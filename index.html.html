📲 Lanzar e Instalar Visor en Móvil o PC

Modo archivo local o servidor web

Instalación directa disponible
Añade TradeView Pro a tu pantalla de inicio como app independiente.
1. Abrir directamente desde tu archivo guardado

Guarda este archivo .html en tu teléfono, tablet o PC y ábrelo con Chrome, Safari o Edge. Todo el visor funciona en el navegador sin instalación previa.

2. Lanzar como App en el Móvil (Android / iPhone)
  • Android (Chrome): abre el menú de tres puntos ⋮ → Añadir a pantalla de inicio (o Instalar aplicación si está servido por HTTPS/localhost).
  • iPhone / iPad (Safari): pulsa Compartir → Añadir a pantalla de inicio para lanzarlo a pantalla completa sin barras del navegador.
3. Flujo ideal: PC de casa → GitHub → Móvil
  1. Sube este archivo como index.html a un repo de GitHub y activa GitHub Pages (https://tuusuario.github.io/tu-repo/). Así lo abres desde cualquier sitio como app PWA.
  2. En el PC de casa, configura tu GitHub Token (permiso gist) en ⚙ API, haz tus cambios (dibujos, Pine, alertas, On-Chain) y pulsa 💾 Guardar → ☁ Subir a GitHub Gist.
  3. En el Móvil, abre la URL, pon el mismo Token y Gist ID en ⚙ API y pulsa 💾 Guardar → ☁ Descargar de Gist para tenerlo igual que en el PC.
